Configuración de Supabase
  1. Crear un proyecto gratuito en supabase.com.
  2. Ejecutar completo supabase-setup.sql en el SQL Editor. Incluye la tabla, permisos y el bucket de imágenes.
  3. En Authentication, habilitar Email/Password, crear el usuario administrador y desactivar registros públicos.
  4. Completar data/nube.json con supabaseUrl, supabaseAnonKey y el mismo adminEmail.
  5. Abrir admin.html, iniciar sesión y tocar Guardar y publicar una vez para subir la carta local.

Las imágenes se guardan en el bucket público carta-imagenes. Mientras la nube no esté configurada, la web usa data/cartas.json como respaldo.
